# CauseBase to CharityGraph migration

This project was formerly developed under the CauseBase name. It is now **CharityGraph**, a rename made to avoid confusion with an unrelated Australian project using that name.

Current development, documentation, repositories, package names, CLI commands, environment variables, generated artefacts, and GitHub Pages use CharityGraph. Historical releases retain their original names and contents. The immutable `v0.5.0-2026-08-15` release is not rewritten.

For one post-0.5 compatibility release, readers may consume legacy `causebase_id` values and selected legacy environment/CLI aliases. Those aliases must warn, be documented, and be removed at the next breaking pre-1.0 contract change. CharityGraph does not create a `charitygraph_id` alias for real-world entities.

CharityGraph is unaffiliated with the Australian project using the CauseBase name.
