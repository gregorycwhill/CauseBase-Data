# Document extraction stack decision — Golden Corpus v1

**Decision class:** Conditional routed adoption
**Date:** 2026-08-15
**Scope:** private Builder evidence processing only; this does not modify the immutable public v0.5 release.

## Superseding ecosystem bake-off result

The initial same-library configuration comparison is superseded by the real
ecosystem bake-off recorded in DOCUMENT_EXTRACTION_ECOSYSTEM_REVIEW.md and the
private `golden-corpus-v1-ecosystem-results.*` reports. The decision is now
computed from hard gates, not hard-coded.

- **Normal digital PDFs / financial reconstruction:** `pdfplumber` passes the
  EJA source-faithful hard gold: P&L 33/33 and Financial Position 32/32, with
  labels, values, comparatives, signs, order and hierarchy preserved.
- **Table specialist:** Camelot stream/lattice were evaluated with a generic
  statement-page rule. Neither displaces the primary route; retain them as
  optional specialists rather than default dependencies.
- **Low-text OCR:** local Tesseract 5.5.3 and RapidOCR 1.2.3 both recovered
  genuine Golden Corpus low-text pages. Tesseract is the simpler default;
  RapidOCR remains available where positioned OCR boxes are needed.
- **Visual charts:** not validated. The configured structured vision adapter
  would transmit EJA annual-report page 29 to OpenAI; that transfer needs
  explicit user authority. Until then the EJA 4/4 visual hard gate remains
  unmet and the overall document state is **CONDITIONAL**.

The current production private pipeline therefore uses `pdfplumber` plus
page-routed local Tesseract. It records vision as unavailable/not validated;
it never fabricates a chart observation. The Document Gate does not pass, so
website/identity evidence-engine work is intentionally not started.

## Evidence

The governed corpus contains 21 cases: seven hard-gold cases and fourteen
review-required diagnostics. It references seven retained private PDFs by
SHA-256; neither the PDFs nor generated extraction results are public/Git
artefacts. The first bounded run exercised the seven report documents using
three meaningful configurations of the installed extraction component:

| Candidate/component | Result | Mean elapsed time across document cases |
| --- | --- | ---: |
| Native text | recovered EJA financial labels; no table structures | 0.617 s |
| Layout text + tables | recovered EJA labels and 59 EJA table structures | 0.662 s |
| Bounded current-style route | same syntax coverage; one unusual report was slower | 1.695 s |

The EJA report's statement pages are 12–13. Native text recovered both
required source labels; downstream financial row reconstruction remains a
separate, provenance-bound stage whose 33 P&L and 32 financial-position rows
are protected by the Golden Corpus target. The visual functional-allocation
labels reached only 3/4 marker recall. The retained reports also contained
low-native-text pages (including 10 Angel Gowns pages and 15 in one Adelaide
Symphony report); no local Tesseract executable was available. Vision routing
was intentionally not configured or invoked.

The private detailed report is generated by `causebase benchmark-golden` into
the mutable runtime directory. It is not a release artefact.

## Selected architecture

Adopt **Document Pipeline v2** as a deterministic, page-routed private
pipeline:

1. Hash the document and extraction configuration; cache the normalised result.
2. Recover native text, positioned word blocks and table structures with
   `pdfplumber`.
3. Route only low-text pages to a locally configured OCR adapter; record an
   explicit `ocr_unavailable` state when no engine is installed.
4. Mark image/curve-heavy pages for a separately configured, cached vision
   adapter. It is never implicit and cannot fabricate a source observation.
5. Leave financial reconstruction, semantic interpretation and public release
   creation to their existing governed stages.

This is conditional rather than a single-library winner: the evidence supports
native/table extraction as the baseline, but does not validate an OCR engine,
visual chart recovery or an independent table parser. Those remain bounded
follow-up comparisons before scale or reliance on those routes.

## Non-decisions and safeguards

- No new annual reports were acquired; the retained seven documents were
  sufficient for this comparison.
- No report PDF, raster, OCR text, raw extraction result, API key or model I/O
  is committed.
- Review-required cases cannot become gold automatically.
- This decision does not authorise corpus expansion, semantic extraction,
  Viewer changes or a new Data release.
